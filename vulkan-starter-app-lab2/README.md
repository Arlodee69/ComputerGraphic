# Lab 2 - Camera and Lighting

Лабораторная 2 на основе первой работы, вариант 2: правильный октаэдр.
Реализованы камера, модель Блинна-Фонга, направленный свет, динамические массивы
точечных и прожекторных источников и их визуализация. Подробное объяснение: [LAB2.md](LAB2.md).

Подготовка к устной сдаче: [DEFENSE.md](DEFENSE.md) — теория, типовые вопросы,
формулы и сценарий демонстрации.

## Сборка и запуск на Windows

```powershell
cd D:\CG\vulkan-starter-app-lab2
cmake --preset mingw-debug
cmake --build build-debug --parallel 4
.\build-debug\vulkan-starter-app.exe
```

Требуются MinGW, CMake, Git и Vulkan SDK с `glslc` в PATH.
При первой конфигурации CMake скачивает GLFW, vk-bootstrap, VMA и ImGui.
После изменения исходников или шейдеров повторяй сборку и запуск.
Приложение нужно закрыть перед пересборкой. Запускай его из корня этого проекта,
поскольку пути к шейдерам относительные.

## Управление

- Панель слева: камера, окружающее освещение, направленный свет, точечные источники, прожекторы, материалы и трансформации моделей.
- `Add` / `Delete` в разделах света добавляют и удаляют выбранный источник, включая удаление последнего.
- `W/A/S/D`: перемещение камеры; `Q/E`: вниз/вверх, когда клавиатура не занята элементом ImGui.
- Правая кнопка мыши и движение курсора над сценой: поворот камеры.
- `Light markers`: яркие кубики источников, направления и конусы прожекторов.
- `Reset scene`: исходная сцена с тремя октаэдрами, полом и всеми типами света.

## Проверки

```powershell
ctest --test-dir build-debug --output-on-failure
.\build-debug\vulkan-starter-app.exe --verify
powershell -NoProfile -ExecutionPolicy Bypass -File tests\verify-window.ps1
```

Последняя команда выполняет проверку со скрытым окном, сохраняет кадры непосредственно
из Vulkan и проверяет их. Снимки и логи находятся в `build-debug/verification/gpu/`.
